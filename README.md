Software people pay to use. Accounts, subscriptions, billing, permissions, scheduled jobs, and the boring parts that have to work every time.

**Shopify apps & ecommerce**
Shopify apps, custom store functionality, storefronts, and the systems behind them.

**Web apps**
One job, done properly, in the browser.

**Custom software**
Software built around how a business actually works instead of forcing the business to work around the software.

**Internal business tools**
The systems your team opens forty times a day. Dashboards, workflows, automations, imports, reminders, approvals, and the things currently living in a spreadsheet.

**Games**
Small games and interactive products built because software does not always have to be serious.

**AI**
Agents and AI systems wired into real data and real workflows, doing work a person would otherwise do by hand.

### How we build

We like software that is fast, obvious, and easy to use.

One clear next action. Words a person would actually say. No unnecessary screens. No system jargon because somebody forgot customers have to read it.

If something can be simpler, it probably should be.
